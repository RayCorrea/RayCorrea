## 👨‍💻 Sobre mim

Sou **Desenvolvedor de Software formado em Análise e Desenvolvimento de Sistemas**, com foco em desenvolvimento **Back-end**, construção de **APIs REST**, bancos de dados relacionais e aplicações web.

Minha trajetória profissional começou na área de **projetos mecânicos e desenvolvimento de equipamentos industriais**, onde adquiri experiência com resolução de problemas, desenvolvimento de projetos, processos industriais e trabalho em ambientes técnicos.

Hoje direciono essa experiência para o desenvolvimento de software, buscando criar aplicações que resolvam **problemas reais de negócio**.

Tenho experiência prática e estudos envolvendo **Python, JavaScript, Node.js, React, PostgreSQL e MySQL**, além de projetos envolvendo desenvolvimento web, APIs, automações e IoT.

Atualmente estou aprofundando meus conhecimentos em **Python, FastAPI, PostgreSQL, Docker, testes automatizados e arquitetura de APIs**.
